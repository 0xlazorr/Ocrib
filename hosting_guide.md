# Ocrib Global Hosting Guide

This guide will walk you through deploying the Ocrib platform to a cloud server so you can access it and send files to your devices from anywhere in the world.

## Prerequisites

1. **A Cloud Server (VPS):** You will need a virtual private server. Providers like [DigitalOcean](https://www.digitalocean.com/), [Linode](https://www.linode.com/), [AWS](https://aws.amazon.com/), or [Hetzner](https://www.hetzner.com/) offer affordable Linux servers (an instance with 1GB RAM and Ubuntu 22.04 LTS is perfect and costs ~$4-5/month).
2. **A Domain Name (Optional but Recommended):** A domain (e.g., `ocrib.yourdomain.com`) makes it much easier to connect your agents and access the web dashboard securely.

---

## Step 1: Server Preparation

Once you have purchased your VPS, log into it via SSH:

```bash
ssh root@your_server_ip
```

Update the system packages to ensure everything is current:

```bash
sudo apt update && sudo apt upgrade -y
```

## Step 2: Install Docker and Docker Compose

Ocrib uses Docker to make deployment as simple as possible. Install Docker with the following commands:

```bash
sudo apt install docker.io docker-compose -y
```

Enable Docker to start automatically if the server reboots:

```bash
sudo systemctl enable docker
sudo systemctl start docker
```

## Step 3: Deploy Ocrib

1. Clone or copy your Ocrib project files to the server. You can use `git` if your project is in a repository, or `scp` to copy the files directly from your local machine.
   
   *(If using `scp` from your local machine to the server):*
   ```bash
   scp -r /path/to/local/Ocrib root@your_server_ip:/opt/ocrib
   ```

2. Navigate into the Ocrib directory on your server:
   ```bash
   cd /opt/ocrib
   ```

3. Start the application using Docker Compose:
   ```bash
   make docker-up
   ```
   *Note: If `make` is not installed, you can run `docker-compose up --build -d` directly.*

Your Ocrib broker is now running! 
- The Web Dashboard is accessible on port **5000**.
- The Agent TCP connection listens on port **8080**.

---

## Step 4: Configure the Firewall

You must ensure that traffic is allowed to reach Ocrib. If you are using Ubuntu's Uncomplicated Firewall (`ufw`), run:

```bash
sudo ufw allow 22/tcp    # SSH Access
sudo ufw allow 5000/tcp  # Web Dashboard
sudo ufw allow 8080/tcp  # Agent Communication
sudo ufw enable
```
*Note: If your cloud provider (like AWS or DigitalOcean) has an external firewall/security group, you must also open ports 5000 and 8080 in their web console.*

---

## Step 5: Connecting Your Agents

Now that your server is hosted globally, you can connect devices from anywhere.

On the receiving device, run the agent and point it to your server's Public IP address (or domain):

```bash
./remote_agent YOUR_SERVER_IP
```

Log into your web dashboard at `http://YOUR_SERVER_IP:5000`, enter the PIN generated by the agent, and you are ready to send files remotely!

---

## Step 6: Production Security (Nginx & SSL/HTTPS) - Recommended

For a secure production environment, you should not expose port 5000 directly. Instead, use Nginx as a reverse proxy and secure the dashboard with a free SSL certificate from Let's Encrypt.

1. **Install Nginx and Certbot:**
   ```bash
   sudo apt install nginx certbot python3-certbot-nginx -y
   ```

2. **Configure Nginx:**
   Create a new Nginx configuration file:
   ```bash
   sudo nano /etc/nginx/sites-available/ocrib
   ```
   Add the following (replace `ocrib.yourdomain.com` with your actual domain):
   ```nginx
   server {
       listen 80;
       server_name ocrib.yourdomain.com;

       location / {
           proxy_pass http://127.0.0.1:5000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       }
   }
   ```

3. **Enable the site and restart Nginx:**
   ```bash
   sudo ln -s /etc/nginx/sites-available/ocrib /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl restart nginx
   ```

4. **Enable HTTPS (SSL):**
   ```bash
   sudo certbot --nginx -d ocrib.yourdomain.com
   ```

5. **Update Firewall (if using Nginx):**
   ```bash
   sudo ufw allow 80/tcp
   sudo ufw allow 443/tcp
   sudo ufw delete allow 5000/tcp # You no longer need port 5000 open to the public
   ```

You can now securely access your dashboard at `https://ocrib.yourdomain.com`.

**Important:** Port 8080 must still remain open (or proxied via a TCP stream) for the C agents to connect to the broker. Your agents would now connect via:
```bash
./remote_agent ocrib.yourdomain.com
```
